## 🚀 Featured project

### CGOC Service Desk

> A role-based IT ticketing system that gives employees and IT teams one place to submit, assign, track, and resolve support requests.

I designed the experience around the responsibilities of four user groups: employees, IT members, IT heads, and administrators.

- **Secure access** — authentication, token refresh, protected routes, and role-based permissions
- **Ticket operations** — search, filters, technician assignment, priority updates, and bulk resolution
- **Team visibility** — responsive dashboards, notifications, attachments, and operational metrics
- **Administration** — user management and audit logging
