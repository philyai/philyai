## What I'm building

### CGOC Service Desk

**An IT ticketing platform for managing support work from first report to final resolution.**

The system gives employees, IT members, IT heads, and administrators their own focused workflows. I built the frontend and the day-to-day ticket experience, including:

- role-based access, protected routes, and token refresh
- ticket search, filtering, assignment, priority, and status changes
- notifications, attachments, bulk resolution, and live dashboard metrics
- user administration and an audit trail for important actions

`React` · `Tailwind CSS` · `Node.js` · `Express` · `SQL`
