## Featured project

### CGOC Service Desk

> A role-based IT ticketing platform for managing support work from the first report to the final resolution.

I built the frontend around four distinct roles: employees, IT members, IT heads, and administrators. Each role gets the tools and information it needs without exposing actions it should not have.

- Authentication, token refresh, protected routes, and permission-based access
- Ticket search, filtering, assignment, priority changes, and status tracking
- Notifications, attachments, bulk resolution, and responsive dashboards
- User administration, audit logging, and real-time operational metrics
